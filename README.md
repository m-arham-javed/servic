# Servic — Local Home-Service Aggregator

**Live Demo:** [servic-alpha.vercel.app](https://servic-alpha.vercel.app)

## Project Overview
**Servic** is a full-stack local service marketplace web application designed to connect homeowners with local tradespeople—including plumbers, carpenters, and maintenance professionals. Built rapidly using **Next.js**, **TypeScript**, and AI-assisted development workflows (GitHub Copilot), the platform streamlines service discovery, provider evaluation, and appointment scheduling.

## Key Features
* **Service Category Discovery:** Browse and filter local service providers across trades (plumbing, carpentry, home repair).
* **Provider Profiles & Details:** Dedicated provider detail views displaying service offerings, availability, and client information.
* **User Authentication:** Secure sign-up and login workflows for clients managing service requests.
* **Appointment Booking & Deduplication:** End-to-end appointment scheduling with built-in booking deduplication logic to prevent duplicate service requests.

## Tech Stack
* **Framework:** Next.js (App Router)
* **Language:** TypeScript
* **Styling:** Tailwind CSS / PostCSS
* **Deployment:** Vercel (CI/CD integrated with GitHub)
